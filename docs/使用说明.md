# 信息表生成器 · 使用说明

文字 + 图片喂进去，出一个素材包 zip，拿去商城后台直接导入。工具本身不联网、不用账号、体内没有 AI；离线可用。

## 一、三个版本，装一个就行

| 版本 | 怎么装 | 第一次打开 |
|---|---|---|
| 苹果手机 / 电脑浏览器（PWA） | 打开网址，Safari 点分享 →「添加到主屏幕」 | 无确认，直接用 |
| 安卓（APK） | 打开 APK 文件安装 | 提示「允许安装未知应用」时点允许（只这一次） |
| Windows（EXE） | 解压 zip，双击文件夹里的「信息表生成器.exe」 | SmartScreen 提示时点「更多信息 → 仍要运行」 |

三个版本功能一样，界面一样。装好后没有网也能干活。

## 二、两个界面，先设模板、再生成

顶部有两个界面，点一下切换：

1. **设置模板**：新建品类、编辑模板、导入模板文件，都在这里做。改好、选好，再去直接生成。
2. **直接生成**：选模板 → 粘贴文字或导入文件 → 核对字段、配好图片 → 点「生成素材包」。

直接生成的三步：

1. **粘贴文字，点「解析文字」**。字段块写法见第三节；也可以点「导入文件」，支持 txt、md、csv、xlsx、xls、docx、json。xlsx 有多张表时，会先让选一张再解析。
2. **核对字段、配好图片**。解析完逐款核对：价格、颜色、尺码、图案、库存都能直接改；点「添加图片」选图，逐张点选归类（主图 / 详情图 / 颜色图 / 尺码图），详情图用 ↑ ↓ 按钮排顺序。
3. **点「生成素材包」**。zip 落到下载文件夹（浏览器版走浏览器下载，安卓/Windows 版直接进系统「下载」文件夹）。一次可录多款，逐个点「生成素材包」，或点「全部出包」一次全出。每款还能单独「只下载信息表」「下载 JSON」「下载 CSV」（按规格组合逐行展开）。

## 三、字段块怎么写

字段词 + 冒号，一行一个字段；多值用顿号分开。示例：

```
款名：重磅素色短袖
分类：短袖
价格：129
运费方式：套模板
描述：240g 重磅棉，宽松版型。
颜色：本白、克莱因蓝
尺码：M、L
图案：素色
库存：100，本白/M/素色=50
```

规则：

- **款名每次出现 = 新开一款**。多款文字连着粘贴就行，工具自动分款。
- **价格**：写数字；¥、元、千分位逗号都认。**运费方式**：只认「包邮」或「套模板」两种写法。
- **库存**：默认全款统一一个数；个别组合单独写「颜色/尺码/图案=数字」覆盖，如上例。统一数不写也可以——只要每个组合都单独写了覆盖数就能出包；缺了哪个组合，报错会点名。
- **款号**：默认取商品名；想指定就加一行「款号：ZB-DX-001」。款号决定 zip 文件名和包内文件夹名。
- 没有字段词的散句，会并入上一个字段（适合补描述）。
- 只有一段没标点的话、拆不开时：先用任意 AI 聊天工具（如 ChatGPT、豆包、DeepSeek）按字段块格式拆好、核对无误再粘进来（工具内不做猜测式拆分，怕拆错价格）。
- 标量文字里的空格会保留（如型号「A 100」不会被压成「A100」）；描述里误写的「字段词：内容」会出警告，提醒检查是不是把描述断错行了。

## 四、图片规矩

- 格式 jpg、png、webp 都行；webp 出包时自动转 jpg。原文件名随便起，出包自动改标准名，不用手改。
- **主图必须有 1 张**，没有主图出不了包。详情图按墙上的顺序出包（从上到下是详情页顺序），用 ↑ ↓ 按钮可调。
- 颜色图要选对颜色：有颜色图但颜色对不上、或同颜色放两张，都会拦截。缺详情图、缺某颜色图只提醒，不拦截。
- 单款最多 12 张图；单张图片不超过 400 万像素（约 2000×2000），超了会拦截，请先压小。

## 五、七个内置模板，换模板即换行业

顶部下拉可切换模板，字段、规格轴、图片规则都随模板走；切换后刷新页面仍保持上次选的模板。

| 模板 | 规格轴 | 能直接导入商城后台吗 |
|---|---|---|
| 服装 | 颜色 × 尺码 × 图案 | 能 |
| 美妆 | 色号 × 规格 × 质地 | 能 |
| 鞋类 | 颜色 × 尺码 × 款式 | 能 |
| 食品 | 口味 × 规格 × 包装 | 不能（标准信息表，须走适配器或等后台升级） |
| 数码 | 颜色 × 内存 × 版本 | 不能 |
| 家居 | 颜色 × 尺寸 × 材质 | 不能 |
| 母婴 | 尺码 × 适用年龄 × 款式 | 不能 |

- **自己加品类**：设置模板界面点「新建品类」，填品类名和 1–3 个规格轴名（如「口味」「规格」），从服装模板复制骨架生成；也可以 0 个轴（无规格、只填库存）。新建的品类自动保存在本机，下次打开还在。
- **编辑模板**：设置模板界面选一个模板，下方编辑器逐行改——模板名、版本号、规格轴改名/增减、字段改名/增删/必填开关、扩展字段增删改（类型、枚举可选值）、图片类别改名/改命名规则/改对应字段。边改边校验，不通过会逐条说清错在哪、保存按钮也是灰的；点「保存模板」才生效。改内置模板会自动另存为副本，原模板不动；改自己导入的模板直接覆盖保存。保存后点「设为生成模板并开始生成」就切回直接生成界面用它出包。
- **模板管理**：每个模板都能导出文件、复制一份、删除；自己导入的模板文件（.json）也会保存在本机，导入同名模板会先问要不要覆盖；损坏的模板文件不会拖垮工具，会进隔离区并提示。
- **扩展字段**：食品的保质期、数码的型号、家居的材质这类本品类才有的信息，写进字段块就能用（如「保质期：12 个月」）；出包时自动追加成新列，也能随信息表读回来。扩展字段是模板自带的，换模板就换一套。

## 六、导入导出格式

- **导入**：txt、md、csv、xlsx、xls、docx、json。csv 支持逗号、分号、制表符分隔（自动识别）；json 支持数组或 `{records: [...]}`，字段词和字段 key 两种键名都认；xlsx 有多张表时可自选一张导入（默认第一张）；信息表 xlsx 读回时，显式填的款号也能找回。
- **导出**：每款可单独「下载 JSON」「下载 CSV」（按规格组合逐行展开，含扩展字段）；「生成素材包」出的 zip 里是标准信息表 xlsx + 图片；「只下载信息表」只出 xlsx。导出的 xlsx、csv、json 都能再导回本工具，组合与库存一致。

## 七、更新

有网时打开工具会自动查一次版本。有新版时顶部弹窗，写明版本号和更新内容；**点「更新」才换版，不点就一直用旧版，绝不自动更新**。安卓/Windows 版点更新后会下载新安装包，末步仍由系统安装确认。

## 八、常见报错

| 提示 | 怎么办 |
|---|---|
| 缺主图 | 给这款选 1 张图归类为主图 |
| 颜色图与颜色对不上 | 颜色图的颜色须与字段里的颜色一字不差 |
| 缺少价格 / 价格格式不对 | 价格栏填数字，如 129、129.5 |
| 运费方式不认 | 只写「包邮」或「套模板」 |
| 库存覆盖指不存在的组合 | 「颜色/尺码/图案=数字」里的组合须真实存在 |
| 缺库存（点名某组合） | 补一个统一库存数，或给缺的组合单独写覆盖数 |
| 日期 / 数字 / 枚举值不对 | 按模板要求写，如日期写 2026-12-01，枚举值须是模板列出的那几个 |
| 组合超过 400 个 | 颜色 × 尺码 × 图案总数须 ≤ 400，拆款处理 |
| 图片超过 12 张 | 单款留 12 张以内 |

工具拦住的错，都是后台导入时会拒绝的错；拦在前面比导进去再返工省事。版本号在界面右上角，报问题时带上版本号和报错原话。
