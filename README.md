# 信息表生成器

文字转表格通用工具：文字 + 图片喂进去，出一个素材包 zip，拿去商城后台直接导入。工具本身不联网、不用账号、体内没有 AI；离线可用。

当前版本：v1.2.0（内置 7 个模板：服装 / 美妆 / 鞋类 / 食品 / 数码 / 家居 / 母婴）。

## 三个版本，装一个就行

| 版本 | 怎么装 |
|---|---|
| 苹果手机 / 电脑浏览器（PWA） | 打开网址，Safari 点分享 →「添加到主屏幕」 |
| 安卓（APK） | 打开 APK 文件安装 |
| Windows（EXE） | 解压 zip，双击文件夹里的「信息表生成器.exe」 |

三个版本功能一样，界面一样。装好后没有网也能干活。

## 怎么用

顶部有两个界面，点一下切换：

1. **设置模板**：新建品类、编辑模板、导入模板文件，都在这里做。改好、选好，再去直接生成。
2. **直接生成**：选模板 → 粘贴文字或导入文件 → 核对字段、配好图片 → 点「生成素材包」。

直接生成的三步：

1. **粘贴文字，点「解析文字」**。字段块写法见下；也可以点「导入文件」，支持 txt、md、csv、xlsx、xls、docx、json。xlsx 有多张表时，会先让选一张再解析。
2. **核对字段、配好图片**。解析完逐款核对：价格、颜色、尺码、图案、库存都能直接改；点「添加图片」选图，逐张点选归类（主图 / 详情图 / 颜色图 / 尺码图），详情图用 ↑ ↓ 按钮排顺序。
3. **点「生成素材包」**。zip 落到下载文件夹（浏览器版走浏览器下载，安卓 / Windows 版直接进系统「下载」文件夹）。一次可录多款，逐个点「生成素材包」，或点「全部出包」一次全出。每款还能单独「只下载信息表」「下载 JSON」「下载 CSV」（按规格组合逐行展开）。

字段块写法：字段词 + 冒号，一行一个字段；多值用顿号分开。示例：

```
款名：重磅素色短袖
分类：短袖
价格：129
运费方式：套模板
描述：240g 重磅棉，宽松版型。
颜色：本白、克莱因蓝
尺码：M、L
图案：素色
库存：100，本白/M/素色=50
```

规则：款名每次出现 = 新开一款；价格写数字；运费方式只认「包邮」或「套模板」两种写法；库存默认全款统一一个数，个别组合单独写「颜色/尺码/图案=数字」覆盖。没有字段词的散句会并入上一个字段。只有一段没标点的话、拆不开时，先用任意 AI 聊天工具按字段块格式拆好、核对无误再粘进来（工具内不做猜测式拆分，怕拆错价格）。

图片规矩：格式 jpg、png、webp 都行；webp 出包时自动转 jpg。**主图必须有 1 张**，没有主图出不了包。单款最多 12 张图；单张图片不超过 400 万像素（约 2000×2000），超了会拦截，请先压小。

## 七个内置模板，换模板即换行业

| 模板 | 规格轴 | 能直接导入商城后台吗 |
|---|---|---|
| 服装 | 颜色 × 尺码 × 图案 | 能 |
| 美妆 | 色号 × 规格 × 质地 | 能 |
| 鞋类 | 颜色 × 尺码 × 款式 | 能 |
| 食品 | 口味 × 规格 × 包装 | 不能（标准信息表，须走适配器或等后台升级） |
| 数码 | 颜色 × 内存 × 版本 | 不能 |
| 家居 | 颜色 × 尺寸 × 材质 | 不能 |
| 母婴 | 尺码 × 适用年龄 × 款式 | 不能 |

自己加品类：在设置模板界面点「新建品类」，填品类名和 1–3 个规格轴名，从服装模板复制骨架生成；也可以 0 个轴（无规格、只填库存）。新建的品类自动保存在本机，下次打开还在。

## 导入导出格式

- **导入**：txt、md、csv、xlsx、xls、docx、json。csv 支持逗号、分号、制表符分隔（自动识别）；json 支持数组或 `{records: [...]}`；xlsx 有多张表时可自选一张导入（默认第一张）；信息表 xlsx 读回时，显式填的款号也能找回。
- **导出**：每款可单独「下载 JSON」「下载 CSV」（按规格组合逐行展开，含扩展字段）；「生成素材包」出的 zip 里是标准信息表 xlsx + 图片；「只下载信息表」只出 xlsx。导出的 xlsx、csv、json 都能再导回本工具，组合与库存一致。

## 更新

有网时打开工具会自动查一次版本。有新版时顶部弹窗，写明版本号和更新内容；**点「更新」才换版，不点就一直用旧版，绝不自动更新**。安卓 / Windows 版点更新后会下载新安装包，末步仍由系统安装确认。

## 从源码构建

- PWA 发行目录：`node tools/build-pwa.mjs`，产物在 `dist-pwa/`。
- 安卓与 Windows 打包脚本在 `tools/`（`build-apk.sh`、`build-exe.sh`）。
- 测试在 `test/`（`npm test`）。注意：部分测试用例依赖 `test/samples/` 下的图片与表格样例文件，仓库里目前只保留了文本样例，图片与表格样例需另外补齐才能完整跑通；`test/run.mjs` 还依赖本机另一份解析器路径。

完整使用说明见 `docs/使用说明.md`。
